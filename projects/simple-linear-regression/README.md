# Simple Linear Regression

A learning notebook exploring the relationship between advertising spend and sales, with regression examples and additional practice exercises.

**Tools:** pandas, NumPy, scikit-learn, statsmodels, Matplotlib, Seaborn.

[View the notebook](analysis.ipynb)

## Run locally or in Colab

1. Download this project folder, or clone the repository.
2. Start Jupyter in this project folder (so `data/` resolves here). For Colab, upload the notebook and the authorised input files with the same folder structure. 
3. Install the relevant packages listed above.
4. The `data/` folder contains `advertising.csv`, `Housing.csv`, and `ad_practice1.csv` for the exercises.
5. Run cells in order and review assumptions before interpreting results.

## Project notes

This educational project includes starter material and exercises. The practice datasets are included in the `data/` folder. Third-party material remains subject to its original terms. Results should be reproduced with the appropriate dataset.

The advertising example uses the Advertising dataset from *An Introduction to Statistical Learning*: https://www.statlearning.com/.
