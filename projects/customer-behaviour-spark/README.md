# Customer Behaviour Analysis with Spark

An Apache Spark coursework implementation covering transaction preparation, joins, cleaning, exploratory analysis, customer segmentation, and RFM analysis. Some instructional conclusion prompts remain in the original work.

**Tools:** PySpark, pandas, NumPy, scikit-learn, Matplotlib, Seaborn.

[View the notebook](analysis.ipynb)

## Run locally or in Colab

1. Download this project folder, or clone the repository.
2. Start Jupyter in this project folder (so `data/` resolves here). For Colab, upload the notebook and the authorised input files with the same folder structure. No Google Drive mount or cloud credentials are needed.
3. Install the relevant packages listed above.
4. Supply these inputs: data/amazon-purchases.csv, data/survey.csv, and data/fields.csv. Obtain the authorised source dataset separately. No S3 account is required for this copy.
5. Run cells in order and review assumptions before interpreting results.
