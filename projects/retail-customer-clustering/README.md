# Retail Customer Segmentation

A learning lab demonstrating RFM feature preparation, scaling, K-means, silhouette analysis, and hierarchical clustering on online retail transactions.

**Tools:** pandas, NumPy, scikit-learn, SciPy, Matplotlib, Seaborn.

[View the notebook](analysis.ipynb)

## Run locally or in Colab

1. Download this project folder, or clone the repository.
2. Start Jupyter in this project folder (so `data/` resolves here). For Colab, upload the notebook and the authorised input files with the same folder structure. 
3. Install the relevant packages listed above.
4. The `data/Online+Retail.csv` file is a 1,500-row random sample of the full dataset. Use the full dataset for representative customer-level RFM analysis; replace the sample CSV with the complete data using the same columns.
5. Run cells in order and review assumptions before interpreting results.

Dataset: Chen, D. (2015), Online Retail, UCI Machine Learning Repository, https://doi.org/10.24432/C5BW33. Licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The included CSV is a 1,500-row random sample, converted from the original dataset to CSV; sampling changes customer histories and results.

## Project notes

This educational project includes starter material and exercises. The sample data is included; obtain the full dataset from UCI for a complete analysis. Third-party material remains subject to its original terms. Results should be reproduced with the appropriate dataset.
