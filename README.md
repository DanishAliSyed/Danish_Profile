# Danish Ali Syed — Data & Analytics Portfolio

Analytics engineering, data platforms, and practical machine learning projects. A collection of projects and exercises exploring data analysis and engineering.

| Project | Focus |
|---|---|
| [NYC Taxi Operations Analysis](projects/nyc-taxi-analysis/README.md) | Exploratory analysis of 2023 NYC yellow taxi trips, including data cleaning, hourly sampling, demand patterns, fare analysis, and geographic visualisation. |
| [Employee Retention Modelling](projects/employee-retention/README.md) | Logistic regression coursework exploring employee retention, with data cleaning, feature engineering, scaling, feature selection, and validation metrics. |
| [Delivery Time Estimation](projects/delivery-time-estimation/README.md) | Regression coursework examining delivery duration through timestamp processing, feature engineering, exploratory analysis, model building, and residual diagnostics. |
| [Customer Behaviour Analysis with Spark](projects/customer-behaviour-spark/README.md) | An Apache Spark coursework implementation covering transaction preparation, joins, cleaning, exploratory analysis, customer segmentation, and RFM analysis.  |
| [Retail Customer Segmentation](projects/retail-customer-clustering/README.md) | A learning lab demonstrating RFM feature preparation, scaling, K-means, silhouette analysis, and hierarchical clustering on online retail transactions. |
| [Multiple Linear Regression](projects/multiple-linear-regression/README.md) | A learning notebook covering multiple linear regression, feature preparation, model diagnostics, and interpretation. |
| [Simple Linear Regression](projects/simple-linear-regression/README.md) | A learning notebook exploring the relationship between advertising spend and sales, with regression examples and additional practice exercises. |
| [Spark SQL Exploration](projects/spark-sql/README.md) | A compact learning notebook demonstrating Spark sessions, CSV loading, temporary SQL views, filtering, sorting, and row-to-dictionary conversion. |

## About the projects

These notebooks include coursework and learning exercises. Datasets are not included; see each project for its data requirements and sources. Results should be reproduced with the appropriate data. Third-party starter material and datasets remain subject to their original terms.
