# Danish Ali Syed — Data & Analytics Portfolio

Analytics engineering, data platforms, and practical machine learning projects. These projects demonstrate analytical workflows; they are educational work, not production deployments.

| Project | Focus |
|---|---|
| [NYC Taxi Operations Analysis](nyc-taxi-analysis/README.md) | Exploratory analysis of 2023 NYC yellow taxi trips, including data cleaning, hourly sampling, demand patterns, fare analysis, and geographic visualisation. |
| [Employee Retention Modelling](employee-retention/README.md) | Logistic regression coursework exploring employee retention, with data cleaning, feature engineering, scaling, feature selection, and validation metrics. |
| [Delivery Time Estimation](delivery-time-estimation/README.md) | Regression coursework examining delivery duration through timestamp processing, feature engineering, exploratory analysis, model building, and residual diagnostics. |
| [Customer Behaviour Analysis with Spark](customer-behaviour-spark/README.md) | An Apache Spark coursework implementation covering transaction preparation, joins, cleaning, exploratory analysis, customer segmentation, and RFM analysis. Some instructional conclusion prompts remain in the original work. |
| [Retail Customer Segmentation](retail-customer-clustering/README.md) | A learning lab demonstrating RFM feature preparation, scaling, K-means, silhouette analysis, and hierarchical clustering on online retail transactions. |
| [Multiple Linear Regression](multiple-linear-regression/README.md) | A learning notebook covering multiple linear regression, feature preparation, model diagnostics, and interpretation. |
| [Simple Linear Regression](simple-linear-regression/README.md) | A learning notebook exploring the relationship between advertising spend and sales, with regression examples and additional practice exercises. |
| [Spark SQL Exploration](spark-sql/README.md) | A compact learning notebook demonstrating Spark sessions, CSV loading, temporary SQL views, filtering, sorting, and row-to-dictionary conversion. |

## About the portfolio

The notebooks were migrated from Colab with outputs and execution metadata removed. They use local input paths and do not require access to private Google Drive files, AWS buckets, or a backend service. Datasets are obtained separately from their authorised sources. Original learning and starter material is identified in each project README. No new licence is applied to third-party material.

The AWS Boto3 notebook, duplicate assignment versions, and general practice scratchpads are excluded from this showcase. The original Drive files are preserved.

These notebooks were checked for JSON structure, Python syntax, private paths, and common credential patterns. They have not been executed as part of the migration, so results and metrics are not independently verified.
