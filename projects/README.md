# Danish Ali Syed — Data & Analytics Portfolio

Analytics engineering, data platforms, and practical machine learning projects. A collection of projects and exercises exploring data analysis and engineering.

| Project | Focus |
|---|---|
| [NYC Taxi Operations Analysis](nyc-taxi-analysis/README.md) | Exploratory analysis of 2023 NYC yellow taxi trips, including data cleaning, hourly sampling, demand patterns, fare analysis, and geographic visualisation. |
| [Employee Retention Modelling](employee-retention/README.md) | Logistic regression exploring employee retention, with data cleaning, feature engineering, scaling, feature selection, and validation metrics. |
| [Delivery Time Estimation](delivery-time-estimation/README.md) | Regression analysis examining delivery duration through timestamp processing, feature engineering, exploratory analysis, model building, and residual diagnostics. |
| [Customer Behaviour Analysis with Spark](customer-behaviour-spark/README.md) | An Apache Spark implementation covering transaction preparation, joins, cleaning, exploratory analysis, customer segmentation, and RFM analysis.  |
| [Retail Customer Segmentation](retail-customer-clustering/README.md) | A lab demonstrating RFM feature preparation, scaling, K-means, silhouette analysis, and hierarchical clustering on online retail transactions. |
| [Multiple Linear Regression](multiple-linear-regression/README.md) | A notebook covering multiple linear regression, feature preparation, model diagnostics, and interpretation. |
| [Simple Linear Regression](simple-linear-regression/README.md) | A notebook exploring the relationship between advertising spend and sales, with regression examples and additional practice exercises. |
| [Spark SQL Exploration](spark-sql/README.md) | A compact notebook demonstrating Spark sessions, CSV loading, temporary SQL views, filtering, sorting, and row-to-dictionary conversion. |

## About the projects

These notebooks include coursework and learning exercises. Datasets are not included; see each project for its data requirements and sources. Results should be reproduced with the appropriate data. Third-party starter material and datasets remain subject to their original terms.
