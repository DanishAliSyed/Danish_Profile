# Loan Portfolio Analysis | Power BI

I built this Power BI project to see where requested loan funding drops off between application, approval, and disbursement. The report also tracks recoveries and lets viewers break down activity by product, channel, and branch.

[View the actual Power BI dashboard export (PDF)](PowerBI_Report_Danish.pdf) · [View the synthetic walkthrough (PDF)](Loan_Portfolio_Analysis.pdf) · [Download the synthetic figures (CSV)](synthetic-loan-summary.csv)

## What the example shows

Of the $24.0M requested in the example, $16.8M (70%) was approved and $14.4M (60%) was disbursed. I would break down the $2.4M gap between approved and disbursed amounts by product, channel, and branch to see where it is concentrated. Recoveries relate to loans already issued, so I would review them separately by loan vintage.

The Power BI export shows the original report visuals as a static PDF. The separate walkthrough and CSV use synthetic figures; those numbers are not from the report.
