# Multiple Linear Regression

A learning notebook covering multiple linear regression, feature preparation, model diagnostics, and interpretation.

**Tools:** pandas, NumPy, scikit-learn, statsmodels, Matplotlib, Seaborn.

[View the notebook](analysis.ipynb)

## Run locally or in Colab

1. Download this project folder, or clone the repository.
2. Start Jupyter in this project folder (so `data/` resolves here). For Colab, upload the notebook and the authorised input files with the same folder structure. 
3. Install the relevant packages listed above.
4. The `data/housing_data.csv` input is included.
5. Run cells in order and review assumptions before interpreting results.

## Project notes

This educational project includes starter material and exercises. The housing practice data is included in the `data/` folder. Third-party material remains subject to its original terms. Results should be reproduced with the appropriate dataset.
